# Data card — synthetic incident-investigation worlds

## Summary

Fully synthetic natural-language dataset of failure investigations at a
fictional battery-cell manufacturing facility, generated by
`belief_feedback.world`. No real persons, organizations, products, or
incidents are described; all names are drawn from fictional name pools and
all identifiers (sample, lot, station, ticket, run ids) are random.

## Motivation

Ground-truthed evidence environments for studying belief dynamics in
multi-agent LMs: every document is backed by a latent evidence event with
known reliability and orientation, so exact Bayesian reference posteriors
exist while agents see only realistic prose.

## Composition

- **Worlds**: one static hidden truth out of two hypotheses
  (`UPSTREAM_CONTAMINATION` vs `LOCAL_CALIBRATION_DRIFT`), counterbalanced
  visible ALPHA/BETA mapping.
- **Events**: 16 families (chromatography, drum retest, supplier change,
  shipping log, flow-meter calibration, warmup drift, work orders, PLC
  logs, failure clustering, mass audit, microscopy, timeline, handover
  notes, release records, independent lab, interviews) with reliabilities
  0.60–0.92 as specified in `world/templates.py`.
- **Reports**: 80–170-word documents with id, title, author, date, visible
  lineage, findings, limitations. Secondary reports restate an existing
  event (same hidden event id, same visible lineage, new report id,
  different prose) and add no normative evidence.
- **Ordinary world composition** (8 agents): 2 private reports per agent,
  16 report instances, 12 unique events, 4 secondary reports, no agent
  holding two reports of one event; smoke scales to 4 agents (8 reports,
  6 events, 2 secondary).
- **Splits**: ten world-disjoint splits (see EXPERIMENT_SPEC.md); test
  splits use only the held-out template variant per family/orientation.

## Files

```
artifacts/data/<config>/worlds.parquet            world-level metadata
artifacts/data/<config>/events.parquet            latent events + LLRs (hidden side)
artifacts/data/<config>/reports.parquet           report metadata + provenance
artifacts/data/<config>/agent_assignments.parquet private assignment map
artifacts/data/<config>/rendered_documents/<world>/<report>.txt
artifacts/data/<config>/splits.json
artifacts/data/<config>/worlds_full.jsonl         full serialized worlds
artifacts/data/<config>/data_validation_report.json
```

The hidden side (events.parquet, worlds_full.jsonl) contains ground truth
and must never be shown to agents; only `rendered_documents` text enters
prompts.

## Validation

`validate-data` checks: word counts within 80–170; no leakage of hypothesis
names, event ids, reliabilities, or likelihood terms into rendered text;
split disjointness; truth and label-mapping balance within one world (per
pair for recycling); template holdout; no duplicate-event assignments; and
the ordinary-world evidence constraints.

## Intended use and limits

For research on belief dynamics, steering, and multi-agent information
flow. The prose is template-generated: it is varied and realistic enough
for evidence-integration experiments, but it is not a corpus of authentic
industrial documents, and stylistic diversity is bounded by the template
bank. Conclusions about real incident-investigation practice should not be
drawn from it.
